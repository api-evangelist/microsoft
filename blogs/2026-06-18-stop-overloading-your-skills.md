Advises against packing excessive documentation into AI agent skills, since models have already ingested most common patterns from public sources and repeating that wastes context window tokens. Recommends a measurement-first approach: measure what the model handles correctly, then build lightweight skills addressing only the remaining 10% of functionality that actually needs support.
